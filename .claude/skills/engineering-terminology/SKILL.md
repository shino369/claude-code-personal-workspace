## Translation Guidelines for Technical Content

### Principle 1: Consistency

Technical terms should remain consistent throughout a document. Create a terminology glossary for each translation project.

### Principle 2: Localization vs. Transliteration

**When to keep English terms**:

- Widely adopted acronyms (API, SDK, GUI)
- Product names and brand names
- Programming language keywords

**When to translate**:

- Conceptual terms that have established translations
- General engineering concepts
- User-facing content

### Principle 3: Context Matters

The same English term may have different translations depending on context:

- "Function" in programming → JA: 関数 / ZH-TW: 函式
- "Function" in general usage → JA: 機能 / ZH-TW: 功能

### Principle 4: Regional Variations

**Japanese Technical Writing**:

- Mix of kanji, katakana, and English
- Katakana used for foreign technical terms (e.g., サーバー for "server")
- Formal technical documents often use more kanji

**Traditional Chinese Technical Writing**:

- Prefer Chinese translations over transliterations
- Use established technical terms from Taiwan/Hong Kong standards
- Software UI often uses 繁體中文 localization standards

## Best Practices

1. **Create Project Glossaries**: For each translation project, maintain a consistent terminology list
2. **Check Official Translations**: For major products (Microsoft, Apple, Google), check their official localized versions
3. **Consider Audience**: Technical depth varies by audience (engineers vs. end-users)
4. **Verify Technical Accuracy**: Always verify that technical translations maintain the correct meaning
5. **Use Reference Materials**: Consult IEEE, ISO standards for standardized terminology

## Quality Checklist

When translating engineering content:

- [ ] Technical terms are accurately translated
- [ ] Acronyms are handled appropriately (keep or translate)
- [ ] Terminology is consistent throughout the document
- [ ] Units and measurements are correctly converted if needed
- [ ] Code samples and technical examples remain clear
- [ ] Mathematical formulas and symbols are preserved
- [ ] Cross-references and citations are properly maintained
